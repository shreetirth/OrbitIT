# OrbitIT 🪐

A live ongoing project that shows the beauty of space and gravity.

## What is this?

A live ongoing project that represents orbital mechanics using 
Physics-Informed Neural Networks. It shows the integration of
Machine learning, Physics and Maths. The results are shown with theories and
possibilities along with beautiful visuals which will  be presented on the OrbitIT website. 

## What's been built so far

- 2D orbital simulation
- 3D orbital simulation with inclination
- PINN vs vanilla NN comparison
- Euler vs Velocity Verlet integrator comparison

## The future

- Figure-8 3-body system
- A 3-body orbital simulation: Sun, Earth, Moon
- A 5-body orbital simulation: Sun + first 4 planets
- Study using different integrators
- A solar system simulation
- Integration of 4D spacetime
